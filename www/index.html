Project Koios

Project Koios is the personal technical website of Eugene Joseph M. Ragasa.

It collects teaching materials, technical notes, computational models, software projects, research sketches, finance-oriented analysis, hardware notes, and other work that does not need to live in a dozen separate places.

The topics vary. The method does not.

Current areas

My work is mostly organized around physics education, computational modeling, materials science, scientific software, inverse problems, uncertainty-aware simulation, and practical technical systems.

Some of this is formal teaching material. Some of it is research. Some of it is software. Some of it is just the record of trying to understand something well enough to build with it.

Working standard

Do not stop at words. If an idea matters, define it. If it can be modeled, model it. If it can be computed, compute it. If it makes assumptions, state them. If it breaks, say where it breaks.

The point is not to make technical work look easy. The point is to make it possible to follow, inspect, reproduce, criticize, and use.

For students and collaborators

Students will find course materials, notes, examples, and computational explanations. Collaborators and technical readers will find research directions, models, software notes, and project logs.

This site is intentionally broad because my work is broad. Project Koios is the umbrella. The separate pieces can become more organized as they grow.
